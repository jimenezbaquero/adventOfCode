# Advent of Code

Soluciones personales de **Advent of Code**, principalmente en PHP.

El objetivo de este repositorio es recopilar y conservar las soluciones de los diferentes años en los que he participado en Advent of Code, así como ir completando los ejercicios que quedaron pendientes.

## Estructura

Las soluciones están organizadas por lenguaje, año y día:

```text
.
├── PHP/
│   ├── 2015/
│   │   ├── day_01/
│   │   ├── day_02/
│   │   ├── day_03/
│   │   └── ...
│   ├── 2020/
│   │   └── ...
│   └── ...
└── README.md
```

Cada directorio `day_XX` contiene las soluciones correspondientes a ese día y, cuando es necesario, los ficheros de entrada utilizados.

## Enfoque

Las soluciones están realizadas buscando principalmente resolver los problemas de forma clara y comprensible, sin intentar necesariamente obtener la implementación más corta o sofisticada.

En algunos casos se utilizan técnicas de optimización cuando el problema lo requiere, pero se intenta mantener la solución sencilla siempre que sea posible.

## Progreso

El repositorio se irá completando progresivamente con las soluciones de los diferentes años.

## Sobre Advent of Code

[Advent of Code](https://adventofcode.com/) es una serie de pequeños problemas de programación que se publican durante el mes de diciembre de cada año.

Cada día contiene dos partes que utilizan el mismo problema, pero cuya segunda parte normalmente introduce una nueva condición o dificultad.
